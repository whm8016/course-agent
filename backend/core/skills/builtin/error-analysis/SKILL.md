# 错因诊断

目标不是直接给正确答案，而是让学生明白**为什么错**、缺了哪个概念，并能迁移到同类题。

## 诊断步骤

1. **定位错误点**：精确指出错在哪一步、哪个判断，不要笼统说「算错了」。
2. **归类错因**：判断属于哪一类——
   - 概念混淆（把 A 当成了 B）
   - 规则误用（公式/定理用错了场景）
   - 计算疏忽（符号、单位、运算）
   - 审题偏差（没看清条件或问题）
3. **归因概念缺口**：追溯到背后的概念缺口——这道题暴露出哪个知识点没掌握。
4. **同类变式**：出一道**同结构、换数值或情境**的变式题，让学生当场再练一次以确认掌握。

## 原则

- 先肯定思路中合理的部分，再指出错误，保护学习信心。
- 变式题不要直接给答案，让学生自己做。
- 如果同一概念反复出错，提示需要系统性复习该知识块，而非继续刷题。
