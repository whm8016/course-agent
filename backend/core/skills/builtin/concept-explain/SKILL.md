# 概念分层讲解

按以下层次讲清一个概念，帮助学生真正理解而非死记。

## 讲解顺序

1. **一句话定义**：用最朴素的语言给出核心定义，不超过两句，避免术语堆砌。
2. **直观类比**：用一个生活或熟悉的类比映射概念的关键特征，并标注类比的边界（哪里像、哪里不像）。
3. **边界与反例**：明确这个概念**不**是什么，点出常见的混淆点和易错情形。
4. **最小例子**：给一个最简单的正例，逐步演算或推理，让学生看到概念如何运作。
5. **回检**：用一个引导式问题（不要直接给答案）确认学生是否真正理解。

## 原则

- 先确认学生已有的前置知识，从那里搭桥，不要假设太多。
- 每一层讲完停一下，观察学生反应再决定是否深入。
- 宁可少而透，不要一次铺十个点。
- 类比必须准确，错误的类比比没有类比更糟。
